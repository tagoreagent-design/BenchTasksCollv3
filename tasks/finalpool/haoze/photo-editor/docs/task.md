# Photo Editor Task

## Description
Build a photo editing tool with filters, adjustments, and basic editing capabilities.

## Requirements
1. Apply filters (vintage, b&w, sepia, etc.)
2. Adjust brightness, contrast, saturation, hue
3. Crop, rotate, resize
4. Remove background
5. Add text, shapes, overlays
6. Support layers
7. Export in multiple formats

## Acceptance Criteria
- Filters apply correctly
- Adjustments work in real-time
- Crop/resize maintains aspect ratio
- Background removal works
- Layers supported
- Export quality options
