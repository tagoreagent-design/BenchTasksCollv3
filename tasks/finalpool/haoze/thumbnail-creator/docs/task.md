# Thumbnail Creator Task

## Description
Build a thumbnail creation tool that generates eye-catching thumbnails for videos and content.

## Requirements
1. Pre-designed templates
2. Custom text with styling
3. Image upload and positioning
4. Branding elements (logo, colors)
5. Multiple size presets (YouTube, Twitch, etc.)
6. A/B test variant generation
7. Export high-resolution images

## Acceptance Criteria
- Templates render correctly
- Text styling works
- Images position accurately
- Branding applied
- Multiple sizes exported
- Variants generated
