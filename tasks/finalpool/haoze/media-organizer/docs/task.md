# Media Organizer Task

## Description
Build a media organization tool that automatically sorts, renames, and manages media files based on metadata.

## Requirements
1. Organize files by type (audio, video, image)
2. Sort by date, artist, album, etc.
3. Rename files with consistent patterns
4. Detect and handle duplicates
5. Fetch missing metadata from online sources
6. Create backup before changes
7. Support custom organization rules

## Acceptance Criteria
- Files organized into correct folders
- Naming patterns applied correctly
- Duplicates identified and handled
- Metadata fetched and applied
- Backup created before changes
