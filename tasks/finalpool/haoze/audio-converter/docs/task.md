# Audio Converter Task

## Description
Build an audio conversion tool that supports multiple formats with configurable quality settings.

## Requirements
1. Convert between MP3, WAV, FLAC, AAC, OGG
2. Adjust bitrate and sample rate
3. Batch conversion with progress
4. Preserve metadata (ID3 tags)
5. Extract audio from video files
6. Preview conversion results

## Acceptance Criteria
- All format conversions work
- Quality settings applied correctly
- Batch processing handles errors
- Metadata preserved
- Video audio extraction works
