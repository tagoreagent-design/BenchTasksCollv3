# Product Catalog Task

## Description
Build a product catalog management system for organizing and publishing products.

## Requirements
1. Create products with attributes
2. Manage variants (size, color, etc.)
3. Organize into categories
4. Set pricing rules
5. Manage product media
6. Publish to sales channels
7. Version control

## Acceptance Criteria
- Products with attributes
- Variants managed correctly
- Categories organized
- Pricing rules applied
- Media attached
- Publishing works
