# Inventory Tracker Task

## Description
Build an inventory tracking system for multi-location stock management.

## Requirements
1. Track inventory by location
2. Manage inter-location transfers
3. Schedule and perform cycle counts
4. Reconcile physical vs system counts
5. Generate inventory reports
6. Low stock alerts per location
7. Audit trail for all movements

## Acceptance Criteria
- Location tracking accurate
- Transfers require approval
- Cycle counts scheduled
- Discrepancies flagged
- Reports per location
