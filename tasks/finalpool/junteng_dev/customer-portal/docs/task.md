# Customer Portal Task

## Description
Build a customer self-service portal with account management, order tracking, and support.

## Requirements
1. User registration and login
2. Profile management
3. Order history with status
4. Support ticket system
5. Knowledge base integration
6. Notification preferences
7. Mobile responsive design

## Acceptance Criteria
- Auth works securely
- Orders display with status
- Tickets can be created/tracked
- Knowledge base searchable
- Mobile friendly
