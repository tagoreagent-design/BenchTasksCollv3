# Contact Manager Task

## Description
Build a contact management system that stores, organizes, and deduplicates contacts.

## Requirements
1. Store contact information (name, email, phone, address)
2. Deduplicate contacts automatically
3. Tag and categorize contacts
4. Track interaction history
5. Import/export (CSV, vCard)
6. Search and filter
7. Relationship mapping

## Acceptance Criteria
- Contacts stored with all fields
- Duplicates merged correctly
- Tags/categories work
- History tracked
- Import/export functional
- Search returns results
