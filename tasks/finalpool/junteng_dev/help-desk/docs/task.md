# Help Desk Task

## Description
Build a help desk ticketing system with routing, SLA management, and reporting.

## Requirements
1. Ticket creation from multiple channels
2. Automatic routing by category
3. SLA tracking and escalation
4. Agent assignment and workload
5. Knowledge base integration
6. Customer communication log
7. Performance dashboards

## Acceptance Criteria
- Multi-channel ticket creation
- Routing rules work
- SLA alerts fire
- Workload balanced
- KB suggestions shown
- Dashboards accurate
