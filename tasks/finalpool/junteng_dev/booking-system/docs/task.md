# Booking System Task

## Description
Build a booking system for appointments, reservations, and scheduling.

## Requirements
1. Check real-time availability
2. Create and manage bookings
3. Handle cancellations and modifications
4. Support waitlists
5. Send confirmation notifications
6. Handle recurring bookings
7. Integrate with calendars

## Acceptance Criteria
- Availability accurate
- No double bookings
- Cancellations processed
- Waitlist managed
- Notifications sent
