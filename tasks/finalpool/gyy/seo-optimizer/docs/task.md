# SEO Optimizer Task

## Description
Build an SEO optimization tool that analyzes web content and provides actionable recommendations for improving search rankings.

## Requirements
1. Analyze on-page SEO factors
2. Check meta tags (title, description, keywords)
3. Validate heading hierarchy
4. Analyze keyword usage and density
5. Check image optimization (alt text, size)
6. Validate internal/external links
7. Generate SEO score and recommendations

## Acceptance Criteria
- All meta tags checked
- Heading structure validated
- Keyword analysis accurate
- Image issues identified
- Link validation works
- Clear recommendations provided
