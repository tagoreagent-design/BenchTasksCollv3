# Blog Engine Task

## Description
Build a blog engine that allows users to create, edit, format, and publish blog posts with markdown support.

## Requirements
1. Create/edit blog posts with markdown editor
2. Support categories and tags
3. Schedule posts for future publication
4. Draft and published states
5. SEO optimization fields
6. Media upload and embedding
7. Comment system integration

## Acceptance Criteria
- Markdown renders correctly
- Posts can be scheduled
- Drafts saved automatically
- SEO fields populated
- Comments work on published posts
