# CMS Builder Task

## Description
Build a content management system that allows users to define content types, create pages, and manage site structure.

## Requirements
1. Define custom content types with fields
2. Create and edit pages
3. Manage site navigation/menu
4. Content versioning and rollback
5. Multilingual content support
6. Media library management
7. Role-based access control

## Acceptance Criteria
- Content types created with various field types
- Pages render correctly
- Navigation updates dynamically
- Version history maintained
- Translations work
