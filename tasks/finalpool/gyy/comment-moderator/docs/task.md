# Comment Moderator Task

## Description
Build a comment moderation system that automatically detects spam, filters inappropriate content, and provides moderation tools.

## Requirements
1. Auto-detect spam using ML/rules
2. Filter profanity and inappropriate content
3. Auto-approve trusted users
4. Queue suspicious comments for review
5. Moderator dashboard with actions
6. Appeal process for flagged content
7. Moderation analytics

## Acceptance Criteria
- Spam detection accuracy > 90%
- Profanity filter works
- Trusted users auto-approved
- Review queue functional
- Appeals process works
