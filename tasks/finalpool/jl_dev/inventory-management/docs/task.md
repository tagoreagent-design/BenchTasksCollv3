# Inventory Management Task

## Description
Build an inventory management system that tracks stock, manages reorders, and optimizes inventory levels.

## Requirements
1. Track real-time stock levels
2. Set and manage reorder points
3. Generate purchase orders automatically
4. Forecast demand based on history
5. Manage supplier information
6. Support multiple warehouses
7. Generate inventory reports

## Acceptance Criteria
- Stock levels accurate
- Reorder alerts work
- POs generated correctly
- Demand forecasting reasonable
- Multi-location supported
