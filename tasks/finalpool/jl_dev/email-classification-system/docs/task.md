# Email Classification System Task

## Description
Build an email classification system that automatically categorizes incoming emails.

## Requirements
1. Classify emails into standard categories
2. Train custom classifiers per user
3. Handle multi-label classification
4. Provide confidence scores
5. Learn from user corrections
6. Process in real-time
7. Integrate with email clients

## Acceptance Criteria
- Standard categories accurate
- Custom training works
- Confidence scores provided
- Learning from corrections
- Real-time processing
