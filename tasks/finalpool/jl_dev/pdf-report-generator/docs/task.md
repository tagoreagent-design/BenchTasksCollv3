# PDF Report Generator Task

## Description
Build a PDF report generator that creates professional reports from data sources.

## Requirements
1. Define report templates
2. Connect to data sources
3. Insert tables, charts, text
4. Apply styling and branding
5. Generate PDF output
6. Schedule automated reports
7. Support multiple page sizes

## Acceptance Criteria
- Templates render correctly
- Data populates accurately
- Charts render properly
- PDF output valid
- Scheduling works
