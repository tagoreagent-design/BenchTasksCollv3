# Monthly Sales Analysis Task

## Description
Build a monthly sales analysis tool that provides insights, trends, and forecasts from sales data.

## Requirements
1. Import sales data from multiple sources
2. Calculate monthly totals and trends
3. Compare month-over-month and year-over-year
4. Identify top-selling products
5. Forecast next month sales
6. Detect anomalies
7. Generate executive dashboards

## Acceptance Criteria
- Data imports correctly
- Trends calculated accurately
- Comparisons work
- Forecasts generated
- Anomalies flagged
- Dashboards render
