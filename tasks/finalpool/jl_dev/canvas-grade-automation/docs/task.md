# Canvas Grade Automation Task

## Description
Build a Canvas LMS integration that automates grading workflows for educators.

## Requirements
1. Connect to Canvas API
2. Create and manage rubrics
3. Configure assignments with grading settings
4. Auto-grade based on rubrics
5. Sync grades to Canvas gradebook
6. Handle late/missing submissions
7. Generate grade reports

## Acceptance Criteria
- Canvas connection authenticated
- Rubrics create correctly
- Assignments configured
- Grades sync accurately
- Reports generated
