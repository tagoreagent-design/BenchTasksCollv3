# Wishlist Manager Task

## Description
Build a wishlist management system that allows users to save, organize, and share desired products.

## Requirements
1. Create multiple wishlists
2. Add/remove items from wishlists
3. Organize items with tags/categories
4. Set price drop alerts
5. Share wishlists publicly/privately
6. Move items to shopping cart

## Acceptance Criteria
- Multiple wishlists supported
- Items can be categorized
- Price alerts work
- Sharing generates valid links
- Cart integration works
