# Coupon Manager Task

## Description
Build a coupon management system for an e-commerce platform that allows creating, validating, and managing discount coupons.

## Requirements
1. Create coupons with different discount types (percentage, fixed amount, free shipping)
2. Validate coupon codes at checkout
3. Apply coupons to orders and calculate discounts
4. Track coupon usage and limits
5. Handle coupon expiration dates
6. Support minimum order requirements
7. Provide admin interface for coupon management

## Acceptance Criteria
- Users can create coupons with all required fields
- Coupon validation works correctly for all discount types
- Usage tracking prevents overuse
- Expired coupons are rejected
- Minimum order validation works
