# Shopping Cart Task

## Description
Build a shopping cart system for an e-commerce platform that allows users to add, remove, and manage items before checkout.

## Requirements
1. Add/remove items from cart
2. Update item quantities
3. Calculate subtotal, tax, shipping, total
4. Apply coupons and discounts
5. Persist cart across sessions
6. Handle out-of-stock items

## Acceptance Criteria
- Items added/removed correctly
- Quantities update properly
- Totals calculated accurately
- Coupons apply correctly
- Cart persists between sessions
