# Loyalty Program Task

## Description
Build a loyalty program system for an e-commerce platform that manages customer points, tiers, and rewards.

## Requirements
1. Award points for purchases based on spending
2. Manage tier system (Bronze, Silver, Gold, Platinum)
3. Allow point redemption for rewards
4. Handle point expiration
5. Track customer lifetime value
6. Provide admin dashboard for program management

## Acceptance Criteria
- Points calculated correctly per purchase
- Tier upgrades/downgrades work automatically
- Reward redemption reduces point balance
- Expired points are removed
- Reports show accurate metrics
