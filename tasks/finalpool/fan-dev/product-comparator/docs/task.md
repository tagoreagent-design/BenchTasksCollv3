# Product Comparator Task

## Description
Build a product comparison tool that allows users to compare multiple products across specifications, features, and prices.

## Requirements
1. Compare up to 5 products simultaneously
2. Display specifications in a table format
3. Highlight differences between products
4. Show price comparisons
5. Allow filtering by category
6. Generate comparison reports

## Acceptance Criteria
- Multiple products displayed side-by-side
- Differences clearly highlighted
- Prices shown for each product
- Category filtering works
- Reports can be exported
