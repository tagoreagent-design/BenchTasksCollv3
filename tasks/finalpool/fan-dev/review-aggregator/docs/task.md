# Review Aggregator Task

## Description
Build a review aggregation system that collects, analyzes, and summarizes product reviews from multiple sources.

## Requirements
1. Collect reviews from multiple platforms
2. Calculate weighted average ratings
3. Perform sentiment analysis on review text
4. Extract common themes and keywords
5. Detect and filter spam reviews
6. Generate summary reports

## Acceptance Criteria
- Reviews collected from all sources
- Weighted average calculated correctly
- Sentiment analysis identifies key sentiments
- Common themes extracted accurately
- Spam reviews filtered out
