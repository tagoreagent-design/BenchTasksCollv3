# Social Connector Task

## Description
Build a social media connector that manages multiple platforms from one interface.

## Requirements
1. Connect Facebook, Twitter, Instagram, LinkedIn
2. Schedule and publish posts
3. Upload media (images, videos)
4. Track engagement (likes, shares, comments)
5. Manage comments and messages
6. Cross-platform analytics dashboard
7. Content calendar

## Acceptance Criteria
- All platforms connect
- Posts publish to all
- Media uploads work
- Analytics aggregated
- Comments manageable
- Calendar functional
