# QR Generator Task

## Description
Build a QR code generator with customization options and multiple data types.

## Requirements
1. Generate QR codes for URLs, text, vCard, WiFi, email
2. Customize foreground/background colors
3. Embed logo in center
4. Adjust error correction (L, M, Q, H)
5. Batch generation
6. Export PNG, SVG, PDF
7. Preview before download

## Acceptance Criteria
- All data types encode correctly
- Colors apply correctly
- Logo embeds without breaking scan
- Error correction levels work
- Batch generation works
- Multiple formats exported
