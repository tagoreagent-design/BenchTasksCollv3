# Currency Converter Task

## Description
Build a currency conversion tool with real-time and historical exchange rates.

## Requirements
1. Convert between 150+ currencies
2. Fetch real-time exchange rates
3. Historical rate queries
4. Support cryptocurrencies
5. Batch conversion
6. Rate alerts
7. Offline mode with cached rates

## Acceptance Criteria
- All major currencies supported
- Real-time rates accurate
- Historical queries work
- Crypto conversion works
- Batch processing fast
