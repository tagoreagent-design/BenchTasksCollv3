# Barcode Scanner Task

## Description
Build a barcode scanning and generation tool supporting multiple formats.

## Requirements
1. Scan EAN-13, UPC-A, QR Code, Code128
2. Generate barcodes from data
3. Batch scan multiple codes
4. Handle damaged/partial codes
5. Validate checksums
6. Export results (CSV, JSON)
7. Camera and image input

## Acceptance Criteria
- All formats scan correctly
- Generation produces valid codes
- Batch processing works
- Damaged codes handled
- Checksums validated
